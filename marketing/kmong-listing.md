# 크몽 입점 킷 — 복붙하면 끝

> 크몽은 결제를 크몽이 대신 받아주고(정산 시 수수료 차감), 개인(비사업자)도 판매를 시작할 수
> 있어서 **사업자등록·토스 가입 없이 첫 매출**이 가능한 가장 빠른 통로입니다.
> 크몽 정산 계좌에 본인 통장을 등록하면 돈이 그 통장으로 들어옵니다.
> (숨고·아이디어스도 같은 방식 — 크몽부터 시작 권장)

## 1. 상품명 (검색 노출용)

```
모바일 청첩장, 24시간 안에 만들어 드립니다 (수정 무제한·전액환불)
```

## 2. 카테고리

디자인 > 인쇄·홍보물 > 청첩장/초대장 (또는 "모바일 청첩장" 검색해 동일 카테고리 선택)

## 3. 패키지 3단 구성 (크몽 STANDARD/DELUXE/PREMIUM에 그대로 입력)

| | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 가격 | 9,900원 | 16,900원 | 24,900원 |
| 제목 | 베이직 청첩장 | 시그니처 청첩장 (BGM) | 프리미엄 청첩장 (BGM+애니메이션) |
| 설명 | 미니멀 템플릿 8종 중 선택, 갤러리 6장, 예식 달력·D-day, 카카오맵·네이버지도, 계좌번호 복사, 공유 기능 | 감성 템플릿 8종 중 선택, 갤러리 12장, 배경음악, 베이직 기능 전부 | 최고급 템플릿 8종 중 선택, 갤러리 20장, 배경음악, 꽃잎·눈·별빛 애니메이션, 표지 인트로 모션 |
| 작업일 | 1일 | 1일 | 1일 |
| 수정 횟수 | 무제한 | 무제한 | 무제한 |

## 4. 서비스 설명 (본문)

```
■ 이런 분께 추천합니다
- 종이 청첩장과 함께 카톡으로 돌릴 모바일 청첩장이 필요한 분
- 대형 업체의 획일적인 디자인이 아쉬운 분
- 빠르고, 수정이 자유롭고, 환불 걱정 없는 곳을 찾는 분

■ 무엇을 받게 되나요
- 나만의 청첩장 링크 (카카오톡·문자로 바로 공유)
- 템플릿 24종 중 선택 (샘플 전부 미리보기 가능 — 아래 링크)
- 사진 갤러리 / 예식 달력·D-day / 카카오맵·네이버지도 / 계좌번호 복사 / 혼주 연락
- 등급에 따라 배경음악, 애니메이션 효과, 인트로 모션

■ 템플릿 미리보기 (실제 작동하는 샘플)
https://kyoobaeklee.github.io/mosida/

■ 진행 순서
1) 결제 후 요청사항 양식에 정보를 적어주세요 (5분)
2) 사진을 채팅으로 보내주세요
3) 24시간 안에 완성 링크를 드립니다
4) 예식 당일까지 수정 무제한

■ 약속
- 24시간 내 완성 (자료 도착 기준, 대부분 훨씬 빠름)
- 수정 횟수 제한 없음
- 완성본이 마음에 안 들면 이유 불문 전액 환불
- 링크는 예식 후 6개월 유지 (연장 무료)
```

## 5. 구매자 요청사항 양식 (크몽 "요청사항"란에 입력)

```
1. 템플릿 이름 (샘플 페이지에서 고른 이름): 
2. 신랑 이름 / 연락처:
3. 신부 이름 / 연락처:
4. 신랑측 혼주 (아버지·어머니 성함, 장남/차남 등):
5. 신부측 혼주:
6. 예식 일시 (예: 2026년 10월 24일 오후 1시):
7. 예식장 이름 / 홀·층 / 주소:
8. 인사말 (비워두시면 저희가 예쁘게 채워드립니다):
9. 계좌번호 안내 필요 여부 (필요 시 은행/계좌/예금주):
10. 사진: 결제 후 채팅으로 보내주세요 (표지 1장 + 갤러리용)
```

## 6. 주문 처리 (사장님 운영 매뉴얼)

크몽 알림 오면 → 요청사항을 JSON으로 정리해 클로드에게 "주문 왔어, 처리해줘" →
`node scripts/make-invite.mjs 주문.json 슬러그` → 사진 교체 → `git push` (Pages 자동 반영)
→ 크몽 채팅으로 `https://kyoobaeklee.github.io/mosida/i/슬러그/` 링크 전달 → 크몽에서 "작업 완료" 처리.

## 7. 등록 절차 (본인만 할 수 있는 일, 약 30분)

1. kmong.com 가입 → "전문가 등록" (개인으로 시작 가능, 크몽 안내 따라 본인인증)
2. 정산 계좌에 본인 통장 등록 ← **돈이 들어오는 곳**
3. "서비스 등록" → 위 1~5번 항목 복붙
4. 썸네일 이미지: 샘플 페이지 스크린샷 사용 (필요하면 "썸네일 만들어줘"라고 요청)
5. 심사 승인(보통 1~3일) 후 판매 시작

## 참고

- 지금 사이트의 "주문하기" 페이지 결제는 테스트 모드입니다(실결제 안 됨).
  실결제는 나중에 사업자등록+토스페이먼츠 후 Vercel로 이전하며 활성화 — 그 전까지 판매는 크몽으로.
- 크몽 수수료(구간별 15~20%대)를 감안해도 서버비 0원이라 남는 구조입니다.
